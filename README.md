# TUGAS-AKHIR-PEMOGRAMAN-WEB
# Sistem Pemesanan Buket Berbasis Web

## Tentang Proyek

Proyek ini merupakan pengembangan website pemesanan buket yang dibuat untuk memudahkan pelanggan dalam melihat produk dan melakukan pemesanan. Website ini dirancang agar pelanggan tidak perlu selalu menanyakan katalog, harga, dan informasi pesanan melalui chat, karena informasi tersebut nantinya dapat dilihat langsung melalui website.

Melalui website ini, pelanggan dapat melihat berbagai pilihan buket, memilih produk yang diinginkan, memasukkan produk ke keranjang, mengisi data pemesanan, serta melakukan pembayaran dan melacak pesanan. Selain itu, website juga menyediakan halaman admin untuk membantu pengelolaan produk, pesanan, dan pembayaran.

Proyek ini dikerjakan sebagai tugas akhir mata kuliah Pemrograman Web.

## Fitur yang Direncanakan

### Pelanggan

- Melihat halaman beranda dan informasi website.
- Melihat katalog buket yang tersedia.
- Melihat detail produk, termasuk gambar, harga, dan deskripsi.
- Menambahkan produk ke keranjang dan mengatur jumlahnya.
- Melakukan pemesanan tanpa harus membuat akun.
- Mengisi data pelanggan dan informasi pengiriman.
- Melihat informasi pembayaran dan mengunggah bukti pembayaran.
- Mendapatkan kode pesanan.
- Melacak status pesanan menggunakan kode pesanan dan nomor WhatsApp.

### Admin

- Login untuk mengakses halaman pengelolaan.
- Melihat ringkasan data pada dashboard.
- Mengelola produk buket.
- Menambah, mengubah, dan menghapus produk.
- Melihat dan mengelola pesanan pelanggan.
- Memperbarui status pesanan.
- Memeriksa dan memverifikasi bukti pembayaran.

## Teknologi yang Digunakan

| Teknologi | Penggunaan |
|---|---|
| HTML | Membuat struktur halaman website |
| CSS | Mengatur tampilan dan desain website |
| JavaScript | Menambahkan interaksi pada halaman |
| PHP Native | Mengelola proses dan fungsi website |
| MySQL/MariaDB | Menyimpan data website |
| XAMPP | Menjalankan website pada lingkungan lokal |

## Dokumentasi Proyek

Dokumentasi proyek disusun dalam folder `docs` agar proses perencanaan dan pengembangan website dapat dilakukan secara teratur.

| Folder | Isi |
|---|---|
| `01-perencanaan` | Latar belakang, tujuan, dan ruang lingkup proyek |
| `02-analisis` | Kebutuhan sistem dan user flow |
| `03-wireframe` | Rancangan awal tampilan halaman website |
| `04-perancangan-database` | ERD, struktur tabel, dan normalisasi |
| `05-perancangan-sistem` | Struktur folder dan arsitektur sistem |
| `06-implementasi` | Dokumentasi proses pembuatan website |
| `07-pengujian` | Rencana dan hasil pengujian sistem |
| `08-penyelesaian` | Dokumentasi hasil akhir proyek |

## Wireframe

Rancangan awal website dibuat secara manual menggunakan kertas HVS untuk menggambarkan susunan halaman, komponen, dan alur penggunaan website. Rancangan tersebut kemudian didokumentasikan dalam bentuk PDF dan digunakan sebagai acuan selama proses pengembangan.

## Tahapan Pengembangan

Pengembangan website dilakukan secara bertahap, mulai dari perencanaan, analisis kebutuhan, pembuatan wireframe, perancangan database, perancangan sistem, implementasi, hingga pengujian.
