# Perancangan Database

Pada tahap ini, kami mulai merancang database yang akan digunakan pada Sistem Pemesanan Buket Berbasis Web. Perancangan database dilakukan untuk menentukan data yang perlu disimpan, hubungan antar-data, serta struktur tabel yang nantinya digunakan dalam proses pengembangan website.

Database dirancang berdasarkan fitur yang telah direncanakan, mulai dari menampilkan produk, menyimpan data pelanggan dan pesanan, mencatat detail produk yang dipesan, hingga mengelola pembayaran dan status pesanan.

## Tujuan Perancangan Database

- Menentukan data yang dibutuhkan oleh sistem.
- Menentukan tabel dan atribut yang digunakan untuk menyimpan data.
- Menentukan hubungan antar-tabel.
- Mengurangi pengulangan data yang tidak diperlukan.
- Menjadi dasar pembuatan database MySQL/MariaDB.

## Dokumentasi Perancangan

Perancangan database akan didokumentasikan melalui beberapa bagian:

- **ERD:** Menggambarkan entitas dan hubungan antar-entitas dalam sistem.
- **Struktur Database:** Menjelaskan tabel, atribut, tipe data, primary key, dan foreign key.
- **Normalisasi:** Menjelaskan proses penyusunan data agar lebih terstruktur dan mengurangi pengulangan data.

## Tahap Selanjutnya

Hasil perancangan database akan digunakan sebagai acuan dalam pembuatan database MySQL/MariaDB dan proses implementasi fitur website menggunakan PHP.
