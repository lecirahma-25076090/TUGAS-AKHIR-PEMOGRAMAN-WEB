# Implementasi

## 1. Deskripsi

Pada tahap ini, kami mulai melakukan proses pembuatan website pemesanan buket berdasarkan rancangan yang telah dibuat pada tahap sebelumnya. Rancangan tersebut mulai diterapkan ke dalam bentuk website yang nantinya dapat digunakan oleh pelanggan dan admin.

Website pemesanan buket ini dibuat untuk memudahkan pelanggan dalam melihat produk, memilih buket, melakukan pemesanan, dan melihat status pesanan. Selain itu, admin dapat mengelola produk, pesanan, dan pembayaran melalui halaman admin.

## 2. Tujuan Implementasi

1. Mewujudkan rancangan website menjadi sebuah sistem yang dapat digunakan.
2. Membuat halaman pelanggan dan halaman admin.
3. Menghubungkan website dengan database.
4. Membuat fitur pemesanan dan pengelolaan produk.
5. Memastikan setiap fitur dapat berjalan sesuai fungsinya.

## 3. Bagian yang Diimplementasikan

Implementasi website pemesanan buket meliputi:

- **Halaman Pelanggan:** Beranda, katalog buket, detail produk, keranjang, checkout, pembayaran, konfirmasi pesanan, dan lacak pesanan.
- **Halaman Admin:** Dashboard admin, kelola produk, kelola pesanan, dan kelola pembayaran.
- **Database:** Penyimpanan data produk, pelanggan, pesanan, dan pembayaran.
- **Fitur Sistem:** Proses pemesanan, pengelolaan produk, dan pembaruan status pesanan.

## 4. Teknologi yang Digunakan

Teknologi yang digunakan dalam proses pembuatan website pemesanan buket meliputi:

- **HTML:** Digunakan untuk membuat struktur halaman website.
- **CSS:** Digunakan untuk mengatur tampilan dan desain website.
- **JavaScript:** Digunakan untuk menambahkan interaksi pada halaman website.
- **PHP:** Digunakan untuk mengolah data dan menjalankan proses pada website.
- **MySQL:** Digunakan untuk menyimpan dan mengelola data website.
- **XAMPP:** Digunakan sebagai server lokal untuk menjalankan website selama proses pengembangan.

## 5. Tahapan Implementasi

Dalam proses pembuatan website pemesanan buket, kami melakukan beberapa tahapan berikut:

1. Menyiapkan folder dan file proyek website.
2. Membuat tampilan halaman pelanggan berdasarkan wireframe.
3. Membuat halaman admin untuk mengelola produk dan pesanan.
4. Membuat database beserta tabel yang dibutuhkan.
5. Menghubungkan website dengan database.
6. Membuat fitur pemesanan dan pengelolaan data.
7. Menjalankan website untuk memastikan fitur dapat digunakan.

## 6. Hasil yang Diharapkan

Melalui tahap implementasi ini, kami berharap website pemesanan buket dapat berjalan sesuai dengan rancangan yang telah dibuat. Setiap halaman dan fitur diharapkan dapat saling terhubung sehingga proses pemesanan oleh pelanggan dan pengelolaan website oleh admin menjadi lebih mudah.
