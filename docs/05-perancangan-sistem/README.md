# 05. Perancangan Sistem

## Deskripsi

Perancangan sistem merupakan tahap yang dilakukan untuk menggambarkan susunan dan cara kerja website pemesanan buket sebelum masuk ke tahap pembuatan program. Pada tahap ini, dilakukan perancangan struktur folder dan arsitektur sistem agar proses pengembangan website lebih terarah dan terorganisir.

Website pemesanan buket ini dirancang untuk memudahkan pelanggan dalam melihat berbagai pilihan buket dan melakukan pemesanan secara online. Selain itu, website juga menyediakan fitur admin untuk mengelola produk dan pesanan pelanggan.

## Tujuan Perancangan Sistem

1. Menentukan susunan folder dan file yang digunakan dalam proyek website.
2. Menjelaskan hubungan antara pengguna, sistem, dan database.
3. Mempermudah proses pengembangan dan pengelolaan website.
4. Memberikan gambaran mengenai cara kerja website pemesanan buket.

## Isi Dokumentasi

Dokumentasi pada tahap perancangan sistem terdiri dari:

- **struktur-folder.md** – Menjelaskan susunan folder dan fungsi masing-masing folder dalam proyek website pemesanan buket.
- **arsitektur-sistem.md** – Menjelaskan komponen sistem, hubungan antarbagian, serta alur kerja website pemesanan buket.

## Hasil yang Diharapkan

Dengan adanya perancangan sistem, proses pembuatan website pemesanan buket diharapkan menjadi lebih terstruktur, mudah dipahami, dan mempermudah pengembangan sistem pada tahap implementasi.
