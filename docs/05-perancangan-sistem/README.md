# Perancangan Sistem

## 1. Deskripsi

Pada tahap ini, kami melakukan perancangan sistem untuk menggambarkan susunan dan cara kerja website pemesanan buket sebelum masuk ke tahap pembuatan program. Kami merancang struktur folder dan arsitektur sistem agar proses pengembangan website lebih terarah dan terorganisir.

Website pemesanan buket ini dirancang untuk memudahkan pelanggan dalam melihat berbagai pilihan buket dan melakukan pemesanan secara online. Selain itu, website juga menyediakan fitur admin untuk mengelola produk, pesanan, dan pembayaran pelanggan.

## 2. Tujuan Perancangan Sistem

1. Menentukan susunan folder dan file yang digunakan dalam proyek website.
2. Menjelaskan hubungan antara pengguna, sistem, dan database.
3. Mempermudah proses pengembangan dan pengelolaan website.
4. Memberikan gambaran mengenai cara kerja website pemesanan buket.
5. Menjadi pedoman dalam proses pembuatan website pada tahap implementasi.

## 3. Gambaran Umum Sistem

Website pemesanan buket ini memiliki dua pengguna utama, yaitu pelanggan dan admin. Pelanggan dapat mengakses halaman website untuk melihat katalog buket, memilih produk, melakukan pemesanan, dan melacak status pesanan. Sementara itu, admin dapat mengelola produk, memeriksa pesanan, dan mengonfirmasi pembayaran pelanggan.

Seluruh data yang digunakan dalam proses tersebut akan disimpan dan dikelola melalui database agar informasi produk, pelanggan, pesanan, dan pembayaran dapat tersusun dengan baik.

## 4. Isi Dokumentasi

Dokumentasi pada tahap perancangan sistem terdiri dari:

- **struktur-folder.md** – Menjelaskan susunan folder dan fungsi masing-masing folder dalam proyek website pemesanan buket.
- **arsitektur-sistem.md** – Menjelaskan komponen sistem, hubungan antarbagian, serta alur kerja website pemesanan buket.

## 5. Hasil yang Diharapkan

Melalui tahap perancangan sistem ini, kami berharap proses pembuatan website pemesanan buket dapat berjalan lebih terstruktur dan mudah dipahami. Rancangan ini juga menjadi pedoman bagi kami dalam melanjutkan proses pembuatan website pada tahap implementasi.
