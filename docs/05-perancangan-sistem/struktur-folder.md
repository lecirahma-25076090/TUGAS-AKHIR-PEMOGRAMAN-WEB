# Struktur Folder Website Pemesanan Buket

## 1. Deskripsi

Struktur folder merupakan susunan tempat penyimpanan file dan dokumen yang digunakan dalam proyek website pemesanan buket. Struktur ini dibuat agar setiap file memiliki tempat masing-masing sesuai dengan fungsinya sehingga lebih mudah ditemukan dan dikelola selama proses pengembangan website.

## 2. Struktur Folder Proyek

```text
TUGAS-AKHIR-PEMOGRAMAN-WEB/
│
├── README.md
├── WIREFRAME PEMESANAN BUKET.pdf
│
├── docs/
│   ├── 01-perencanaan/
│   ├── 02-analisis/
│   ├── 03-wireframe/
│   ├── 04-perancangan-database/
│   ├── 05-perancangan-sistem/
│   │   ├── README.md
│   │   ├── struktur-folder.md
│   │   └── arsitektur-sistem.md
│   ├── 06-implementasi/
│   ├── 07-pengujian/
│   └── 08-penyelesaian/
│
├── database/
│
├── assets/
│
├── src/
│
└── tests/
```

## 3. Penjelasan Fungsi Folder

**1. README.md**

Digunakan untuk memberikan informasi umum mengenai proyek website pemesanan buket.

**2. docs/**

Digunakan untuk menyimpan seluruh dokumentasi proyek, mulai dari perencanaan hingga penyelesaian website.

**3. database/**

Digunakan untuk menyimpan file database SQL yang berisi struktur tabel dan data yang diperlukan oleh website.

**4. assets/**

Digunakan untuk menyimpan file pendukung tampilan website, seperti gambar buket, ikon, dan aset lainnya.

**5. src/**

Digunakan untuk menyimpan kode program utama website, termasuk halaman pelanggan, halaman admin, dan konfigurasi sistem.

**6. tests/**

Digunakan untuk menyimpan file dan dokumentasi yang berkaitan dengan pengujian website.

## 4. Tujuan Struktur Folder

Struktur folder ini dibuat agar penyimpanan file proyek lebih teratur dan tidak tercampur. Dengan pembagian folder berdasarkan fungsinya, proses pembuatan, pengembangan, dan pemeliharaan website pemesanan buket dapat dilakukan dengan lebih mudah.
