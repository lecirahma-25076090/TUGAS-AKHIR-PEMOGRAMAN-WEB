# Dokumentasi Wireframe

## 1. Pengertian Wireframe

Wireframe merupakan rancangan awal tampilan website yang menggambarkan susunan elemen, navigasi, dan fungsi pada setiap halaman sebelum website dikembangkan. Wireframe Sistem Pemesanan Buket Berbasis Web dibuat secara manual menggunakan kertas HVS sebagai gambaran awal tampilan dan alur penggunaan website.

## 2. Tujuan Wireframe

Wireframe dibuat dengan tujuan:

- Memberikan gambaran awal tampilan website yang akan dikembangkan.
- Menentukan susunan elemen pada setiap halaman website.
- Mempermudah proses pengembangan antarmuka website.
- Menjadi acuan dalam proses implementasi menggunakan HTML, CSS, dan JavaScript.
- Memastikan alur pemesanan pelanggan dan pengelolaan admin dirancang dengan jelas.

## 3. Rancangan Halaman

Wireframe Sistem Pemesanan Buket Berbasis Web terdiri dari rancangan halaman pelanggan dan halaman admin.

### A. Halaman Pelanggan

1. Beranda.
2. Katalog Buket.
3. Detail Produk.
4. Keranjang.
5. Checkout.
6. Pembayaran.
7. Konfirmasi Pesanan.
8. Lacak Pesanan.

### B. Halaman Admin

1. Login Admin.
2. Dashboard.
3. Kelola Produk.
4. Kelola Pesanan.
5. Kelola Pembayaran.

## 4. Bentuk Wireframe

Wireframe dibuat secara manual pada kertas HVS dengan menggambarkan susunan elemen, komponen, tombol, dan navigasi pada setiap halaman. Rancangan tersebut kemudian didokumentasikan dalam bentuk file PDF agar dapat digunakan sebagai acuan dalam proses pengembangan website.

## 5. File Wireframe

Dokumentasi rancangan wireframe tersedia pada file `WIREFRAME PEMESANAN BUKET.pdf` yang berada di repository utama proyek.

File tersebut digunakan sebagai referensi visual dalam proses implementasi halaman website.

## 6. Tahap Selanjutnya

Wireframe yang telah dibuat akan digunakan sebagai acuan dalam perancangan database, penentuan struktur sistem, dan proses implementasi website.
