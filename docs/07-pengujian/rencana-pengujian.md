# Rencana Pengujian Website Pemesanan Buket

## 1. Deskripsi

Pada tahap ini, kami menyusun rencana pengujian untuk memastikan setiap halaman dan fitur pada website pemesanan buket dapat berjalan sesuai dengan fungsinya. Pengujian dilakukan pada halaman pelanggan maupun halaman admin agar kesalahan atau kendala yang mungkin terjadi dapat diketahui dan diperbaiki.

## 2. Tujuan Pengujian

1. Memastikan setiap halaman website dapat dibuka dengan baik.
2. Memeriksa apakah fitur-fitur website berjalan sesuai fungsinya.
3. Mengetahui kesalahan atau kendala yang terjadi pada website.
4. Memastikan proses pemesanan dapat dilakukan oleh pelanggan.
5. Memastikan admin dapat mengelola produk, pesanan, dan pembayaran.

## 3. Ruang Lingkup Pengujian

Pengujian dilakukan pada dua bagian utama website, yaitu:

- **Halaman Pelanggan:** Beranda, katalog buket, detail produk, keranjang, checkout, pembayaran, konfirmasi pesanan, dan lacak pesanan.
- **Halaman Admin:** Dashboard admin, kelola produk, kelola pesanan, dan kelola pembayaran.

## 4. Persiapan Pengujian

Sebelum melakukan pengujian, kami menyiapkan beberapa hal berikut:

1. Website pemesanan buket yang akan diuji.
2. Perangkat komputer atau laptop.
3. Browser untuk membuka website.
4. Data produk dan data pemesanan sebagai bahan pengujian.
5. Akun admin untuk menguji fitur pengelolaan website.

## 5. Rencana Pengujian Halaman Pelanggan

| No. | Fitur yang Diuji | Hal yang Diperiksa |
|---|---|---|
| 1 | Beranda | Halaman dapat dibuka dan informasi tampil dengan baik. |
| 2 | Katalog Buket | Daftar produk buket dapat ditampilkan. |
| 3 | Detail Produk | Informasi nama, harga, dan deskripsi produk tampil. |
| 4 | Keranjang | Produk dapat ditambahkan dan jumlahnya dapat diubah. |
| 5 | Checkout | Formulir pemesanan dapat diisi dan dikirim. |
| 6 | Pembayaran | Informasi pembayaran dapat ditampilkan dan bukti transfer dapat diunggah. |
| 7 | Konfirmasi Pesanan | Kode pesanan dapat ditampilkan setelah pemesanan berhasil. |
| 8 | Lacak Pesanan | Pelanggan dapat melihat status pesanannya. |

## 6. Rencana Pengujian Halaman Admin

| No. | Fitur yang Diuji | Hal yang Diperiksa |
|---|---|---|
| 1 | Dashboard Admin | Informasi ringkasan dapat ditampilkan. |
| 2 | Kelola Produk | Admin dapat menambah, mengubah, dan menghapus produk. |
| 3 | Kelola Pesanan | Admin dapat melihat dan memperbarui status pesanan. |
| 4 | Kelola Pembayaran | Admin dapat melihat bukti pembayaran dan mengonfirmasi pembayaran. |

## 7. Metode Pengujian

Pengujian direncanakan menggunakan metode Black Box Testing. Metode ini dilakukan dengan mencoba fitur website menggunakan data masukan tertentu, kemudian memeriksa apakah hasil yang ditampilkan sudah sesuai dengan yang diharapkan. Pengujian dilakukan tanpa melihat kode program di dalam sistem.

## 8. Hasil yang Diharapkan

Melalui rencana pengujian ini, kami berharap seluruh fitur website pemesanan buket dapat berjalan dengan baik sesuai dengan fungsinya. Apabila ditemukan kesalahan atau kendala, kami akan melakukan perbaikan agar website dapat digunakan dengan lebih baik.
